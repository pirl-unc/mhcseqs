# Legacy species-prefix audit (2026-08-31)

This audit answers which short species codes in the pre-full-binomial
`mhcseqs` diverse corpus had external evidence and which were synthesized by
the retired curation rule. The complete, machine-readable result is
[`species_prefix_audit_pre_full_binomial.csv`](species_prefix_audit_pre_full_binomial.csv).

## Result

The audit covers 425 distinct `(species, prefix)` pairs:

| Classification | Pairs | Meaning |
|---|---:|---|
| `external_registry_or_literature` | 7 | The code is in the explicit mhcseqs allowlist and has a database or paper URL. |
| `external_uniprot_label` | 310 | The exact code occurs in a raw UniProt gene or protein label for the same accession/species. |
| `generated_by_mhcseqs_2plus2` | 103 | The code exactly matches the retired first-two-genus + first-two-species rule and is absent from the available raw source labels. |
| `source_label_artifact` | 4 | The historical token is recoverable, but is a generic gene/product label rather than a species prefix. |
| `source_foreign_nomenclature_alias` | 1 | The historical token is a mouse-system synonym on a rat record, not a rat species prefix. |

Thus 317 pairs have external evidence, 103 were definitely generated by
mhcseqs, and all 21 formerly unresolved pairs now have accession-level source
provenance. Of those 21, 16 are source-attested prefixes, four are generic
label/parser artifacts (`I`, `MHC II H2`, and `MHC` for two species), and the
rat `H2` token is a mouse-system synonym of the primary `RT1-M10-ps4` gene. A
code appearing in UniProt is evidence of external use, but not necessarily
evidence that a nomenclature committee formally designated it.

The exact 103 generated and 21 recovered pairs are recorded as individual CSV
rows, together with row counts, example accessions, raw labels, and evidence
URLs. Representative generated examples include `Pste` for
*Pseudonaja textilis*, `Lala` for *Laticauda laticaudata*, `Nana` for *Naja
naja*, `Pomu` for *Podarcis muralis*, and `Xetr` for *Xenopus tropicalis*.

## Historical provenance recovery

The machine-readable
[`historical_prefix_provenance_20260831.csv`](historical_prefix_provenance_20260831.csv)
pins all 239 packaged records represented by the 21 formerly unresolved pairs.
It records the exact source gene and protein labels, UniProt entry version,
last-modified date, release, retrieval date, source URL, classification, and a
primary-paper URL where one is available. Two hundred records remain in
UniProtKB release `2026_02`; 39 deleted records were recovered from their
latest UniSave versions, last present in release `2026_01`.

The recovered raw labels are also populated in the packaged corpus's
`raw_gene_label` field. Canonical full-binomial genes are unchanged. Only the
170 records across 16 genuinely source-attested prefix/species pairs enter the
short-alias registry; generic labels and the foreign-system synonym do not.

## Policy applied after this audit

- Canonical mhcseqs output uses the concatenated full binomial, such as
`PseudonajaTextilis-DRA` or `HomoSapiens-A*02:01`.
- Short codes are accepted only as source/input aliases when a database or
  publication establishes them.
- Source codes are retained in raw-source or ortholog provenance fields; they
  are not synthesized for species that lack one.
- Recovered historical codes are treated as aliases only when the source label
  uses them as taxon-specific nomenclature; generic and foreign-system tokens
  remain provenance only.

## Supported external aliases

The packaged [`mhc_prefix_aliases.csv`](../mhcseqs/mhc_prefix_aliases.csv)
extends the corpus audit with the current IPD-MHC register and historical
nomenclature papers. It contains 476 source-attested `(taxon, prefix)` rows:

| Evidence class | Aliases | Source |
|---|---:|---|
| `ipd_current` | 137 | All designation tokens for the 125 organisms in the IPD-MHC taxonomy register. |
| `formal_system` | 14 | HLA, H2, RT1, BoLA, SLA, ELA, OLA, CLA, DLA, FLA, RLA, Gaga, Sasa, and Dare. |
| `literature_historical` | 27 | Superseded or study-specific systems such as HL-A, H-2, B, Smh, Ag-B/H-1, GPLA, XLA, `Livea`, and eight old NHP designations. |
| `external_database` | 298 | Exact short prefixes retained in UniProt/GenBank gene or protein labels after de-duplication against the rows above. |

Twenty-seven normalized spellings have more than one source-attested taxonomic
claim. They are supported only with explicit species context. For example,
`Gogo-DAB` is unsafe by itself because `Gogo` is used for both *Gorilla
gorilla* and *Gobio gobio*, whereas `parse_allele_name("Gogo-DAB",
species="Gobio gobio")` is unambiguous. The same rule covers collisions such
as `Bubu`, `Hyam`, `Hymo`, `Moal`, `ORLA`, `Paha`, `RAJA`, and `Sama`.

Generic source labels (`I`, `MHC`, and `MHC II H2`) are not species codes and
were excluded. Historical `Smh` is registered with its publication evidence,
but full molecule parsing remains blocked until mhcgnomes models *Spalax
ehrenbergi*; this is tracked in
[mhcgnomes#136](https://github.com/pirl-unc/mhcgnomes/issues/136).

Two source labels that appeared in the legacy gene field rather than its
generated prefix—published amphibian `Livea` and GenBank/UniProt `Frcoe`—are
also registered. Their corpus rows use `~ref:` provenance because neither
label identifies a standard locus by itself.

## Reproduction

Run the audit script against a pre-migration curated CSV and its corresponding
raw UniProt download:

```bash
python scripts/audit_species_prefixes.py \
  --curated path/to/legacy/diverse_mhc_sequences.csv \
  --raw path/to/diverse_mhc_raw.csv \
  --output data/species_prefix_audit_pre_full_binomial.csv
```

Rebuild the formerly missing accession snapshot directly from the pinned
pre-migration corpus and the official UniProtKB/UniSave APIs:

```bash
python scripts/recover_historical_prefix_provenance.py \
  --retrieved-on 2026-08-31 \
  --update-corpus
```
